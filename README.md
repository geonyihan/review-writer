# 리뷰 라이터

실제로 겪은 일만 적으면, 고른 플랫폼 양식에 맞춰 성호 님 말투로 리뷰를 만들어 주는 개인용 모바일 웹앱입니다.
빌드 도구 없이 `index.html` 하나로 동작하고, GitHub Pages에 그대로 올릴 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI + 로직 + 프롬프트). 단일 파일 |
| `manifest.json` | 홈 화면에 추가(PWA)용 매니페스트 |
| `sw.js` | 앱 셸 오프라인 캐시 (API 요청은 캐시하지 않음) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |

## 쓰는 법

1. 앱을 열고 오른쪽 위 **⚙️ 설정**에서 Gemini API 키를 넣습니다.
   - [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → 구글 로그인 → **API 키 만들기** → 복사해서 붙여넣기 (무료)
   - 기본 모델은 `gemini-3.5-flash`이고, `gemini-3.8-flash`(품질 우선) / `gemini-3.5-flash-lite`(빠름)로 바꿀 수 있습니다.
   - 2026년 11월 기준 Gemini 2.5/2.0 Flash는 지원이 끝났거나(2.0) 12월 1일에 종료 예정(2.5)이라 3.x 모델을 씁니다.
2. 플랫폼을 고르고(여러 개 가능), 이름·평가·겪은 일을 적고 **리뷰 만들기**를 누릅니다.
3. 카드마다 **복사**를 눌러 해당 앱에 붙여넣습니다. 무신사는 **한줄평만** 버튼이 따로 있습니다.
4. 만든 리뷰는 **🗂 내역**에 최근 100개까지 저장됩니다. 카드의 **다시 쓰기**로 그 플랫폼만 다른 문장으로 다시 뽑을 수 있습니다.

## 지원 플랫폼과 톤

- 식당·장소: 카카오맵(가장 솔직·냉정), 네이버지도(경험·팩트 중심, 게시중단 리스크 회피), 구글맵(결론 먼저, 직관적), 다이닝코드(맛·가격·서비스)
- 뷰티·패션: 글로우픽, 화해(좋았던 점/아쉬웠던 점/추천 피부타입/재구매 의사 구조), 무신사(사이즈·핏·소재, 체형 반영), 올리브영(사용감 중심 + 사진 팁)
- 공통: 20대 후반 남성 직구체(`~함`, `~음`, `~임`, `~네요`, `~듯`), 과장·미사여구·이모지 없이, 메모에 없는 사실은 지어내지 않음, 비추일 때는 억지 칭찬 없이 단점을 분명히.

## 데이터

- API 키, 모델 설정, 체형 스펙, 작성 내역은 모두 브라우저 `localStorage`에만 저장됩니다. 서버로 보내지 않습니다.
- 리뷰 생성 시에만 입력 내용이 Google Gemini API로 전송됩니다.
- 공용 기기에서는 쓰지 마세요. 설정에서 키를 지우면 즉시 삭제됩니다.

## 배포 (GitHub Pages)

```bash
git init
git add .
git commit -m "add review writer app"
git branch -M main
git remote add origin https://github.com/<계정>/<레포>.git
git push -u origin main
```

레포 Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `/ (root)` → Save.
잠시 뒤 `https://<계정>.github.io/<레포>/` 로 열립니다. (무료 Pages는 public 레포에서만 동작)

안드로이드 크롬에서 그 주소를 열고 메뉴 → **홈 화면에 추가**를 누르면 앱 아이콘이 생깁니다.
